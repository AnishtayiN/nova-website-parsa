# نوآوا - سایت + پنل مدیریت (PHP + JSON Database)

سایت کامل با پنل مدیریت واقعی. بدون نیاز به MySQL - دیتابیس JSON با قفل‌گذاری فایل.

## ویژگی‌ها

- پنل مدیریت کامل
- دیتابیس JSON با امنیت بالا
- احراز هویت امن
- هدرهای امنیتی
- صفحات مختلف (خانه، درباره ما، خدمات، نمونه کارها، تماس)
- تم تاریک/روشن
- واکنش‌گرا
- انیمیشن‌ها

## راه‌اندازی

### پیش‌نیازها
- PHP 8.0+
- Apache/Nginx
- دسترسی نوشتن به فایل‌ها

### نصب
1. فایل‌ها را به سرور کپی کنید
2. فایل config.env.php را ویرایش کنید
3. از دسترسی نوشتن به پوشه data/ اطمینان حاصل کنید
4. به سایت دسترسی پیدا کنید: http://localhost/nova-website-parsa

### ورود به پنل مدیریت
- نام کاربری: admin
- پسورد: admin123 (لطفاً آن را تغییر دهید)

## ساختار پروژه

- config.php - پیکربندی مرکزی
- config.env.php - تنظیمات محیطی
- index.php - صفحه اصلی
- admin.php - پنل مدیریت
- auth.php - احراز هویت
- api.php - API endpoints
- data/ - دیتابیس JSON
- js/ - اسکریپت‌ها
- css/ - استایل‌ها
- pages/ - صفحات

## امنیت

- حفاظت CSRF
- حفاظت XSS
- سشن‌های امن
- حفاظت در برابر Brute Force
- قفل‌گذاری فایل‌ها
- هدرهای امنیتی
