STEP 1: ریپازیتوری جدید در GitHub بسازید
----------------------------------------

   1. در مرورگر خود به آدرس زیر بروید:
      https://github.com/new

   2. فیلدها را به این صورت پر کنید:
      
      Repository name:     nova-website-parsa
      Description:         سایت کامل نوآوا - استودیو خلاقیت دیجیتال با پنل مدیریت
      Public/Private:     Public
      Initialize:         ❌ هیچکدام را انتخاب نکنید ( important! )
      
   3. روی "Create repository" کلیک کنید

   4. حالا صفحه ریپازیتوری شما باز می‌شود:
      https://github.com/YOUR_USERNAME/nova-website-parsa

================================================================================

STEP 2: آدرس ریپازیتوری را کپی کنید
-------------------------------------

   روی دکمه "Code" کلیک کنید
   آدرس را کپی کنید ( با .git در انتها )
   مثال: https://github.com/AnishtayiN/nova-website-parsa.git

================================================================================

                      اگر خطا گرفتید:

================================================================================

 خطا: "Repository not found"
   حل: از آدرس درست با .git در انتها استفاده کنید

 خطا: "failed to push some refs"
   حل: git pull origin master --allow-unrelated-histories
        git push -u origin master

 خطا: "Authentication failed"
   حل 1: از SSH استفاده کنید:
        git remote set-url origin git@github.com:USER/REPO.git
        git push -u origin master
   
   حل 2: credential helper را تنظیم کنید:
        git config --global credential.helper store
        git push -u origin master
